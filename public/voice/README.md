# Живой голос для шлема

Положите сюда mp3-файлы с этими именами — шлем проиграет запись (с радиоэффектом) вместо
синтезатора речи. Нет файла — фразу говорит лучший русский голос системы. Записывайте спокойно,
как в эфире, без пауз в начале и в конце; 1–3 секунды на фразу.

| Файл | Текст |
|---|---|
| `abort-dust_storm.mp3` | Пыльная буря впереди. Прерываем выход, возвращайся на базу. |
| `abort-dust_devil.mp3` | Пылевой вихрь впереди. Прерываем выход, возвращайся на базу. |
| `abort-rockfall.mp3` | Камнепад впереди. Прерываем выход, возвращайся на базу. |
| `abort-solar_storm.mp3` | Солнечная вспышка. Прерываем выход, возвращайся на базу. |
| `route-home.mp3` | Маршрут домой есть. Иди по синим меткам. *(синтезатор ещё называет расстояние)* |
| `route-home-updated.mp3` | Маршрут домой обновил. |
| `no-way.mp3` | Чистого пути назад нет. Стой на месте, ждём. |
| `recall-ship.mp3` | Это корабль. Возвращайся, маршрут уже у тебя. |
| `new-route.mp3` | Новый маршрут у тебя. |
| `off-route.mp3` | Ушёл с маршрута. Перестраиваю. |
| `no-reroute.mp3` | Отсюда не проложить. Вернись к линии. |
| `on-target.mp3` | Всё, ты на точке. |
| `airlock.mp3` | Шлюз. С возвращением. |
| `alert-dust_storm-route.mp3` | Пыльная буря на маршруте. |
| `alert-dust_storm-route-critical.mp3` | Пыльная буря на маршруте! |
| `alert-dust_storm-zone.mp3` | Пыльная буря рядом. |
| `alert-dust_storm-forecast.mp3` | Внимание, скоро пыльная буря. |
| `alert-dust_devil-route.mp3` / `-zone` / `-forecast` | Пылевой вихрь на маршруте. / …рядом. / Внимание, скоро пылевой вихрь. |
| `alert-rockfall-route-critical.mp3` / `-zone` | Камнепад на маршруте! / Камнепад рядом. |
| `alert-solar_storm-planet-critical.mp3` | Солнечная вспышка. Срочно в укрытие. |
| `alert-solar_storm-planet.mp3` | Солнечная вспышка. Будь внимателен. |

Сообщения диспетчера и корабля (свободный текст) всегда читает синтезатор.
